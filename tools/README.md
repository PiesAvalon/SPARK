# Upstream Tool Sources

The source code under `tools/` is derived from the public repositories of the following nine upstream testing tools:

| Local directory | Upstream project | Upstream repository |
| --- | --- | --- |
| `COMET` | COMET | <https://github.com/maybeLee/COMET.git> |
| `DevMuT` | DevMuT | <https://github.com/Wayne-coding/DevMuT.git> |
| `Gandalf` | Gandalf | <https://github.com/Gandalf401/Gandalf.git> |
| `GenCoG` | GenCoG | <https://github.com/wzh99/GenCoG.git> |
| `LEMON` | LEMON | <https://github.com/Jacob-yen/LEMON.git> |
| `ModelMeta` | ModelMeta | <https://github.com/anonymous-tai/ModelMeta.git> |
| `Muffin` | Muffin | <https://github.com/library-testing/Muffin.git> |
| `neuri-artifact` | NEURI | <https://github.com/ise-uiuc/neuri-artifact.git> |
| `nnsmith` | NNSmith | <https://github.com/ise-uiuc/nnsmith.git> |

These local copies are included for the SPARK artifact and benchmark integration. Compared with the original upstream repositories, we made minor modifications where needed for artifact integration, compatibility, path/configuration cleanup, and experiment reproduction.

The original code, authorship, and licensing terms remain with the respective upstream projects. Please refer to each upstream repository and its license files for the original project details.
